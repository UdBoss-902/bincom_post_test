# Bincom Academy Python Post-Training Test

This repository contains the completed solutions for the Bincom Academy Python Beginners Class Post-Training Test.

## Repository Structure

- `fibonacci/` - Contains the Fibonacci series generator task.
- `todo_app/` - Contains the PostgreSQL-backed To-Do list application.

> **Note:** Please refer to the individual `README.md` file located inside each subfolder for detailed setup instructions, prerequisites, and usage guidelines for each specific task.
