# Task 1: Fibonacci Series Generator

A Python script that generates the Fibonacci sequence up to a specified number of terms using a generator function (`yield`).

## Features
- **Memory Efficient**: Utilizes Python generators (`yield`) to compute sequence values dynamically on demand.
- **Interactive CLI**: Allows users to input the desired number of terms interactively.
- **Input Validation**: Gracefully handles non-positive numbers and invalid non-integer inputs.

## Prerequisites
- Python 3.x installed on your machine.

## How to Run

1. Open your terminal or command prompt.
2. Navigate to the `fibonacci` directory:
   ```bash
   cd fibonacci

3. Run the Python script:
python fibonacci.py
Enter the number of terms when prompted (e.g., 10).
